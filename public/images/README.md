# Add your images

Copy your image files into this folder, then update the matching image path in
[`src/content.ts`](../../src/content.ts). For example, if you add `hero.jpg`
here, set the hero image to `/images/hero.jpg`.

Image paths for the hero, about, and industries sections are under `images`.
Product card images are under `products.items`; gallery images are under
`gallery.images`. Each image entry also has an `alt` value—update it to describe
your image for accessibility.

Supported browser-friendly formats include JPG, PNG, WebP, and AVIF. Keep image
file sizes reasonable so the website loads quickly.
